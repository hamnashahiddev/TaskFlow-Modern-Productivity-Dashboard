# 🤝 Contributing to TaskFlow

First of all, thank you for your interest in contributing to **TaskFlow**! 🎉

Whether you're fixing a bug, improving the user interface, updating documentation, or suggesting a new feature, your contribution is greatly appreciated.

## 📖 About TaskFlow

TaskFlow is a modern SaaS-inspired productivity dashboard designed to help users organize tasks, track progress, and stay focused through a clean, minimalist, and responsive user experience.

Our goal is to build an intuitive productivity application that is simple, fast, and enjoyable to use.

---

# 🚀 Getting Started

Follow these steps to set up the project locally.

### 1. Fork the Repository

Click the **Fork** button at the top right of this repository.

---

### 2. Clone Your Fork

```bash
git clone https://github.com/your-username/TaskFlow.git
```

Replace `your-username` with your GitHub username.

---

### 3. Navigate into the Project

```bash
cd TaskFlow
```

---

### 4. Install Dependencies

```bash
npm install
```

---

### 5. Start the Development Server

```bash
npm run dev
```

The application should now be running locally.

---

# 🌱 Create a New Branch

Before making any changes, create a new branch.

```bash
git checkout -b feature/your-feature-name
```

Example:

```bash
git checkout -b feature/task-search
```

---

# 💻 Development Guidelines

Please follow these guidelines when contributing:

- Write clean and readable code.
- Keep components modular and reusable.
- Follow the existing folder structure.
- Use meaningful variable and function names.
- Avoid unnecessary dependencies.
- Test your changes before submitting.

---

# 🎨 UI Guidelines

TaskFlow follows a minimalist design philosophy.

Please ensure that any UI changes:

- Maintain a clean and modern appearance.
- Preserve responsive behavior.
- Keep spacing and typography consistent.
- Avoid unnecessary visual clutter.
- Support both Light and Dark Mode where applicable.

---

# 🐛 Reporting Bugs

If you discover a bug, please include:

- A clear description
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

---

# 💡 Suggesting Features

Feature requests are always welcome.

When submitting a feature request, please explain:

- The problem you're trying to solve
- Your proposed solution
- Why it would improve TaskFlow

---

# ✅ Pull Request Process

Before submitting a Pull Request:

- Ensure your code builds successfully.
- Test all affected functionality.
- Update documentation if necessary.
- Keep Pull Requests focused on a single feature or fix.
